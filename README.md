# Task Manager API

## Description
A beginner-friendly RESTful Task Manager API built with Python and Flask.

This project is designed to practice and understand the fundamentals of backend development, REST APIs, CRUD operations, databases, validation, authentication, and API testing.


## Features
- Create tasks
- View tasks
- Update tasks
- Delete tasks

## Technologies
- Python
- Flask
- SQLite
## Future goal
A RESTful Task Manager API built with Python and Flask, featuring CRUD operations, SQLite database integration, input validation, and authentication.
